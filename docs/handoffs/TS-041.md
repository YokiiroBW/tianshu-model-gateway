## 协调审查修正：SSE event 字段

基于首次实现提交 `b6188f22e8b7e04c0757a54f4905bf4ed6e97916` 追加修复。协调者确认 `event:error` 被遗漏；新增真实 HTTP 回归在修改前复现 LF、CRLF、CR 三种无空格写法全部错误地正常结束（1 个测试内 3 个失败子例），带空格写法会正确中止。

`StreamObserver` 现按第一个冒号分出字段名和值，冒号后最多去一个空格；记录事件最终 event 值，在事件分派时判定 error，并在空行重置事件类型。无冒号字段取空值，注释/未知字段忽略，保留多 data 行连接和现有三类换行处理。规则依据 [HTML SSE 解释算法](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation)。不是整行字面匹配，也不把第二个空格、Tab 或大小写变体自动等同于 error。

补充组件回归覆盖两种 error 写法 × 三种换行 × 每个双分片边界，以及 event 最后值覆盖、空值重置、无 data 事件、`event:error` 搭配 `[DONE]` 和无冒号 data。真实 HTTP 回归在完成 choice 后发送 error 事件与 `[DONE]`，核对错误事件已交付字节及后续收到的前缀与上游相同，随后连接中止、回执 outcome=unknown / usage_complete=false / fallback_used=false，内部原因为 incomplete_stream，连接和并发槽释放。生产转发代码未改写；原有断流、超时、取消和成功工具流检查继续通过。
