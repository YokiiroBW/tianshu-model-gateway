## 发现并修复的缺陷

新测试在真实 native 路径上暴露一处实现缺陷并已修复：`native_finish()` 的度量 INSERT 用了 12 个占位符写 13 列（漏了 `credential_namespace`），导致每次 native 度量写入抛 `sqlite3.OperationalError`。它在 `send_responses()` 的 finally 中抛出，因此（a）native 回执永远停在 `in_flight`，（b）已经完整交付给调用方的原生响应被 `gateway_internal_error` 改判为 502 `result_unknown`。修复方式是两条 INSERT 都写出显式列名，并由新增组件用例 `test_native_finish_writes_one_row_the_native_report_can_read` 与 HTTP 用例共同锁住。修复后 native 原有 49 项与新增 32 项全部通过，说明该缺陷此前只影响新私有表写入，未改变既有回执/字节保真语义。
